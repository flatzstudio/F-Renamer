# F Renamer

[🇬🇧 English](README.md) · 🇷🇺 Русский
Простая, быстрая и нативная утилита для массового переименования файлов в macOS.

F Renamer изначально создавался как небольшой инструмент для ускорения рутинной работы с файлами в музыкальном продакшне. Со временем проект вырос в универсальную утилиту для переименования файлов.

Главная идея проста:

> **Быстро переименовать файлы без лишней возни.**

## Возможности

- Массовое переименование нескольких файлов
- Импорт файлов из выбранной папки
- Drag & Drop файлов и папок
- Предпросмотр изменений перед переименованием
- Отмена последней операции переименования
- Очистка текущего списка файлов
- Преобразование названий в Title Case
- Работа с WAV-файлами и папками
- Нативный интерфейс macOS на SwiftUI
- Поддержка русского и английского языков
- Локальная обработка файлов без загрузки данных на сервер

## Зачем нужен F Renamer?

Переименование большого количества файлов — одна из тех мелких задач, которые постоянно отнимают время.

F Renamer создан для того, чтобы сделать этот процесс максимально простым:

**выбрать файлы → увидеть результат → переименовать.**

Никаких сложных настроек и многоступенчатых меню.

## Требования

- macOS 12.0 или новее
- Apple Silicon или Intel Mac

## Установка

Скачайте последнюю версию приложения со страницы [Releases](../../releases) и переместите **F Renamer.app** в папку «Программы».

## Использование

### Выбор папки

Нажмите **Choose Folder...** и выберите папку.

F Renamer просканирует её и покажет файлы, доступные для переименования.

### Выбор файлов

Для выбора отдельных файлов используйте **Choose WAV Files...** или просто перетащите файлы в окно приложения.

### Drag & Drop

Перетащите файлы или папку непосредственно в область Drag & Drop.

Папки сканируются только на верхнем уровне — вложенные директории автоматически не обрабатываются.

### Переименование

После выбора файлов F Renamer показывает предварительный результат изменений.

Проверьте результат и примените переименование.

### Отмена

Если необходимо отменить последнее переименование, используйте кнопку **Undo Last Rename**.

## Разработка

F Renamer написан специально для macOS и использует:

- Swift
- SwiftUI
- AppKit
- Xcode

Проект не использует Electron или другие кроссплатформенные фреймворки.

## Локализация

F Renamer поддерживает русский и английский интерфейс.

Переключение языка осуществляется непосредственно в приложении.

## Конфиденциальность

F Renamer работает локально на вашем Mac.

Приложение не загружает файлы, имена файлов или другую пользовательскую информацию на удалённые серверы.
