# F Renamer

[English](README.md) · Русский

F Renamer - нативная утилита macOS для очистки и стандартизации имён многодорожечных WAV-файлов. Приложение анализирует набор файлов, показывает редактируемый предпросмотр, проверяет целевые имена и выполняет переименование транзакционно. Содержимое аудиофайлов не читается и не изменяется.

## Требования

- macOS 14 или новее
- Apple Silicon (arm64)

## Возможности

- Добавление WAV-файлов или сканирование верхнего уровня папки; расширение `.wav` определяется без учёта регистра.
- Распознавание префиксов с номерами дорожек, общих частей имён и поддерживаемых названий инструментов.
- Необязательная капитализация с сохранением технических и музыкальных обозначений.
- Предпросмотр и ручное редактирование каждого предлагаемого имени.
- Защита от перезаписи и одинаковых целевых имён; попытка отката при ошибке пакетного переименования.
- Быстрое действие Finder для передачи папки или WAV-файлов в обычный предпросмотр приложения.
- Английский и русский интерфейс.

## Сборка и тесты

Запустить тесты:

```sh
swift test --arch arm64
```

Соберите приложение и расширение Finder в Xcode, используя схему `MultitrackCleaner`. Чтобы установить и проверить быстрое действие Finder, выберите команду подписи в Xcode. Team ID разработчика не хранится в проекте.

См. [CHANGELOG.md](CHANGELOG.md) и [Documentation/TEST_CASES.md](Documentation/TEST_CASES.md) для списка изменений и ручной проверки Finder.

Архив версии 1.0.0 для этого кандидата не подписан и предназначен только для локальной оценки. Для подписи приложения и включения быстрого действия Finder выберите свою команду Apple Development в Xcode.

## Конфиденциальность и безопасность

F Renamer работает локально. Учётная запись, облако, телеметрия и подключение к сети не требуются. Имена меняются только после предпросмотра и подтверждения. Существующие файлы не перезаписываются.
