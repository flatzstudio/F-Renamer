# F Renamer 1.0.0

F Renamer cleans and standardizes multitrack WAV filenames on macOS. Review and edit proposed names before applying changes. The app protects existing files from overwrites and changes filenames only; audio content is not modified.

## Requirements

- macOS 14 or later
- Apple Silicon (arm64)

## Included

- Batch WAV filename analysis with track-number and shared-segment detection.
- Editable preview, optional capitalization, and collision validation.
- Transactional rename with rollback attempt on failure.
- Finder Quick Action and English/Russian interface.

## Distribution Status

This is an unsigned local release candidate. It has not been published, notarized, or distributed through GitHub or the Mac App Store. Select an Apple Development team in Xcode to sign and locally test the Finder Quick Action. Public distribution requires appropriate Developer ID signing and notarization.
